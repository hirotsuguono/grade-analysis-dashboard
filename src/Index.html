    効果量（Cohen's d / dz）とは

    「平均が5点上がった」——それが大きな変化なのか、誤差の範囲なのかは、点数だけでは分かりません。みんなが60点前後に固まっている集団での5点と、20〜90点までバラバラな集団での5点は、意味がまったく違うからです。

    効果量は、変化や差を「点数のばらつき（標準偏差）」を物差しにして測り直した値です。別集団の比較には d、同じ生徒の前後比較には差分を基準にした dz を表示します。

    d = ±0.2 未満ごく小さい（誤差の可能性が高い）
    d = 0.2〜0.5小さい変化
    d = 0.5〜0.8中くらいの変化（体感できる差）
    d = 0.8 以上大きな変化

    ※ 効果量は「大きさ」の指標であって、授業や支援が原因だったことの証明ではありません。テストの難易度や受験者が違う場合、単純比較はできません。人数が少ないときは参考程度に扱ってください。

    名簿管理

    成績は氏名ではなく内部IDで紐づくため、クラス替えで「クラス・番号」を変えても過去の成績は引き継がれます。

    新年度のクラス名簿を貼り付けてください。氏名で照合し、クラスと出席番号を更新します（成績は保持）。

    テストを追加

    実施学年＝「何年生のときのテストか」。実施日を設定すると、後から過去のテストを追加しても時系列が正しく並びます。

    分野

    同じ教科では毎回同じ分野名を使うと、分野別の推移が年をまたいでつながります（「前回の構成をコピー」が確実です）

    問題

    問題を登録すると、合計点・分野別点は問題の得点から自動計算されます。問題なし（合計点のみ）でも作成できます。

    Excelからの貼り付け

    Excelで点数の範囲をコピーし、表の任意のセルを選択して Ctrl+V（Macは ⌘V）で貼り付けられます。

    • 貼り付けた位置を起点に、右方向＝問題、下方向＝生徒の順で流し込まれます
    • 列の順番は表の問題の並びと合わせてください
    • 空セルは無視されます（既存の値を消しません）
