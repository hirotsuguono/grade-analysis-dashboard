# 全国調査比較のデータと取込仕様

全国学力・学習状況調査などの公開集計と自校の結果を、同じ年度・設問・尺度・集計条件で比較する機能の設計。既存のテスト、数値指標、5段階アンケート、RTI支援とは独立した調査データを扱う。

## 利用の流れ

1. 全国・地域の公式Excel原本を読み込み、年度、学校段階、地域、設置者区分、回答者、集計条件、読めた表を確認する。
2. 比較する質問・教科と自校の入力方式を選び、対応する学校用Excelを発行する。
3. 学校値を記入したExcelを読み込み、追加・修正・空欄に戻る値を確認して一括反映する。
4. 学校・比較先・差を図表で確認する。調査回、学校結果、比較対象、出典をJSONへ保存してオフラインで再開する。

集計値だけの利用では名簿を要求しない。個人別回答では、調査時点の対象者IDと所属を保存する。進級・卒業・名簿削除で、保存済みの調査の対象者や集計を変えない。

## 保存するデータ

ルートのJSON `version` は3を維持し、任意の `surveys` 拡張に専用の `schemaVersion` を置く。拡張のない既存JSON v1–v3は従来どおり扱う。

```js
surveys: {
  schemaVersion: 1,
  sources: [],
  instruments: [],
  references: [],
  waves: []
}
```

| データ | 保持する内容 |
|---|---|
| `sources` | 出典、ファイル名、取込日、利用可能なファイル指紋、読取器の識別子・版、元シート・セル範囲。指紋は内容識別用で、公的機関による真正性の証明とはしない |
| `instruments` | 調査年度、学校段階・学年、回答者、設問原文、選択肢のコードと意味、教科・技能範囲、尺度と単位 |
| `references` | 比較対象の地域・設置者・対象者・分母定義を持つ公式統計と原表の注記 |
| `waves` | 自校の実施回、実施日、選択した質問・教科、固定した対象者、利用する比較対象、自校結果の版履歴 |

公式資料の年度と、自校が質問を実施した日は別項目にする。設問番号や同じ質問名だけでは資料を対応付けず、質問文、選択肢、対象条件を含む定義で識別する。地理区分の「全国」と設置者区分の「公立」は別軸として保持する。

訂正値は元の結果を残して追加し、差し替える結果を識別する。学校結果の重複判定は同じ調査回内で行い、別の実施回は値が同一でも保存する。各調査回が参照する設問定義・公式統計の版を固定し、改訂資料で過去の比較を自動更新しない。個人別と集計値の二方式を、同じ対象について加算しない。統計ごとに採用元を記録し、公式学校集計と個票集計の切替時は変更を確認する。学校の公式IRT平均と個人バンド分布は別統計として併用できる。

回答集計だけで選択肢の文言を確認できない設問は `codesOnly` とする。後から追加した対応資料と年度・学校段階・学年・回答者・設問原文・回答コードが一致した場合は、選択肢を補完した新しい定義と公式統計の版を追加する。旧版は `supersedes` で識別し、統計値・分母・出典セルは変更しない。新しい調査回の候補には確認済みの版を表示し、作成済みの調査回は元の版を参照し続ける。同じ資料の再取込では版を重複追加しない。

## 統計型と比較の条件

| 型 | 内容 |
|---|---|
| `distribution` | 回答選択肢別、正答数別、IRTバンド別などの人数・割合 |
| `summary` | 対象人数と、教科の平均・単位。掲載されている場合の標準偏差など |
| `crossTab` | 回答と教科結果など、実際に対応付けられた同時分布 |
| `conditionalMean` | 回答選択肢別など、条件ごとの教科平均と対象人数 |

全ての表に、観測単位、対象条件、分母の定義と人数、掲載値の精度、欠測状態を持たせる。クロス表は行内割合・列内割合・全体割合を区別する。分母の定義が既知で人数だけ未掲載の場合は、その旨を表示して記述比較を許可する。分母の定義が不明な場合は差を計算しない。「生徒」と「学校」、「質問調査参加者」と「質問・教科の両方に参加した者」、「英語3技能」と「英語4技能」を区別する。

教科尺度は、平均正答率、素点、IRTスコア、IRTバンドを別型にする。全国と自校は同じ尺度・単位・試験範囲で比較する。平均正答率とIRTスコアを同じ軸へ載せない。IRTは支援のRTIや評定へ変換しない。教科ごとに試験フォーム、尺度の版、バンド境界と端点の包含条件を保持する。同じ教科・満点・技能範囲だけでは同一尺度と認定せず、異なるフォームは公式の接続根拠がある場合に限り比較する。

- 表・設問ごとの対象人数を使い、通常の名簿人数を全問共通の分母にしない。
- 未入力、無回答、対象外・未出題、無効回答、調査不参加、未提供、秘匿を区別する。0点・0人・0%は有効な実数として扱う。
- 割合しかない表から人数を逆算しない。公表値の丸めを勝手に100%へ補正しない。
- 回答コードを点数とはみなさず、全設問に一律の番号平均・上位2択・反転を適用しない。
- 自校の回答分布だけからクロス表を作らない。個人別の回答と教科結果を結べる場合は、有効な組の人数を使う。
- IRTバンドだけから平均IRTスコアや選択肢別平均を推定しない。学校の返却平均と、個人バンドの分布は別入力にする。
- 年度切替は別の比較を開く操作とする。経年比較には設問・尺度の接続根拠を別途必要とする。
- 単一校の学校質問は「自校の回答」と「全国で同じ回答をした学校の割合」を表示し、自校を100%として差を計算しない。

比較判定は `comparable`、`referenceOnly`、`blocked` と理由を返す。年度・学校段階・質問・選択肢・対象者・母集団・試験範囲・尺度・分母が不明または不整合の場合は、意味のある差を確定しない。全国／県／自校という地域差と人数差は意図する比較軸であり、同一であることを要求しない。`comparable` のみ差を表示し、`referenceOnly` は理由付きの参考表示として差を出さず、`blocked` は比較グラフを生成しない。全国値に自校が含まれ得るため、既存の独立2群検定をそのまま適用しない。

## Excelの取込と学校用テンプレート

公式Excelは年度・資料の種類ごとの読取器で扱う。ファイル名やURLの数字だけで年度・集計対象を決めない。実ブックの正式見出し、選択肢、表構造、対象者、注記を使って認識し、曖昧な結果はプレビューで止める。

学校用テンプレートは二種類とする。

- 集計値用：回答別人数または割合、教科の公式平均などを入力する。人数方式と割合方式は発行時に区別する。
- 個人別用：固定IDで質問回答と教科結果を対応付ける。氏名は任意。既存名簿のIDを使う場合も、調査時点の所属・参加条件を固定する。

質問文・選択肢・単位・年度・調査回ID・テンプレート版は確認用とし、学校値の入力欄は空欄で発行する。空欄を「無回答」などの回答コードへ自動変換しない。調査回ID・設問定義・尺度・対象者に加えて、発行した質問・教科・入力範囲を保持して検証する。差し替えでは対象範囲内の空欄だけを消去候補とし、対象外の質問や結果は保持する。

学校返却集計から転記する場合、学校別に返却されない項目を必須入力にしない。令和8年度中学校のランダム出題52項目などは「未提供」として扱う。学校が独自に再実施した回答は、公式実施とは別の調査回に保存する。

読込は検査、プレビュー、確定の順とし、エラー時は部分反映しない。遅れて完了した旧ファイルや、JSON切替前のプレビューを適用しない。失敗時はデータ、保存先、ファイル名、未保存状態を保持する。直前の取込の取消は当該調査だけに作用し、その後に入力した通常テストや指導メモを巻き戻さない。取消の対象範囲と適用後の結果版を照合し、後から同じ調査内で変更した別の結果も保持する。

公式原本のサイズ・シート数・列数・ZIP展開量を確認し、専用読取器の上限を設定する。既存の学校用Excelの制限を一律に緩めない。数式を実行せず、必要な数値・文字列と元の欠測状態を取り出す。原本の加工や一部範囲のコピーを利用者へ要求しない。

## 画面と実装の境界

既存7パネルを残し、「全国・地域比較」を追加する。起動画面にも専用入口を置く。準備後は取込・差し替え操作を折り畳み、質問検索、比較先の切替、学校・比較先・差を中心に表示する。年度・学校段階・比較地域・設置者区分・学校側の対象範囲はグラフと常に一緒に表示する。人数、詳しい分母の説明、出典、元の掲載値は詳細に置く。グラフと同じ内容を読める表を併設する。

`survey-core.js` は定義・検証・比較判定、`survey-state.js` は取込の確定・取消と個票集計、`survey-import.js` は公式読取器、`survey-templates.js` は学校テンプレート、`survey-ui.js` は操作と描画を担当する。既存 `metrics` の1〜5自動判定・同名更新や、通常テストの0〜100検証を全国データへ流用しない。

JSONの読込・保存の両方で拡張を検証する。読取器はアプリの状態を直接変更せず、候補データと読み取れなかった範囲を返す。取込確定時にだけ状態を更新する。

実行時に全国データを自動送信・取得する通信は追加しない。利用者が選択した公開Excelをブラウザ内で処理し、必要な正規化値と出典を保存する。原本のブック全体や生徒データを外部へ送信しない。
