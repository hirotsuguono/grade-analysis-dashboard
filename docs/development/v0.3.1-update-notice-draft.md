# v0.3.1 の更新案内案（未公開）

この文面は検討用です。既存 Release の本文や配布先は変更していません。
正式な v0.4.1 Release が承認・公開されるまでは、正式版への更新案内として公開しないでください。

---

v0.3.1 をご利用の方へ：修正版 v0.4.1 では、JSON の型チェックと読込失敗時のデータ保持、Excel 取込の容量・範囲制限、分野名の安全な表示、同梱ライブラリとライセンス表示を改善しました。PIN は誤操作防止用で、JSON の暗号化ではありません。

更新前に現在の JSON を保存し、元のアプリと JSON を残してください。修正版 ZIP は別フォルダへすべて展開し、新しい Index.html から保存済み JSON を開いて、名簿・点数・支援記録を確認してください。データの形式は v1〜v3 を引き継げます。

ECharts には既知修正を含む 6.1.0 を同梱しています。v0.3.1 の本アプリで、告知された問題の発生条件が成立することを確認したものではありません。

不具合を報告するときは、実名・成績・支援記録・実際の JSON や Excel・画面写真を添付せず、体験用の架空データと再現手順、アプリの版・OS・ブラウザを使ってください。
