# 成績分析ダッシュボード

テストの点数・アンケート・支援記録を、パソコン上で記録して分析するアプリです。

## ダウンロードして使う

**[配布用ZIPをダウンロード](https://github.com/hirotsuguono/grade-analysis-dashboard/releases/latest/download/grade-analysis-dashboard.zip)**

ダウンロードできない場合は[予備のリンク](https://github.com/hirotsuguono/grade-analysis-dashboard/raw/refs/heads/main/downloads/grade-analysis-dashboard.zip)をお試しください。

1. ZIPを**すべて展開**します。Windowsは右クリック→「すべて展開」、MacはZIPをダブルクリックします。
2. 展開したフォルダの **`Index.html` をダブルクリック**して、ブラウザで開きます。
3. 操作方法は、アプリ右上の **「使い方ガイド」** をご覧ください。

インストール・アカウント登録・サーバーの操作は不要で、オフラインでも使えます。`Index.html` と `files` フォルダは離さず保管してください。コードが表示された場合は、`Index.html` を右クリックしてブラウザで開いてください。

**自動保存はありません。** 変更後は「保存」でJSONをダウンロードし、次回は「保存したJSONを開く」で最新版を選んでください。JSON・Excel・印刷物には入力した情報が含まれるため、保存先や共有相手を確認してください。
